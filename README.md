# 西立佛 · 云冈石窟第 20 窟

11 页动效放映稿，保存的是 2026 年 9 月 26 日最终修订的本地演示版本。

## 下载后直接放映

**[点击下载 xilifo.html](https://github.com/yk4642d97f-boop/yungang-xilifo/releases/latest/download/xilifo.html)**

1. 下载完整的 `xilifo.html`（约 5.9 MB）。
2. 在电脑上用最新版 Chrome 或 Edge 打开这个文件。
3. 按 **F** 全屏；**← / →** 或 **空格** 翻页。点击右下角声音图标开启环境声和音效。

照片、字体、深度图、掩膜、页面样式和脚本均在 HTML 内。下载后可以断网播放，不需要安装 Node.js、Python 或启动服务器。

GitHub 文件页面显示的是源码；要观看动画，请下载 HTML 后在浏览器中打开。也可以通过仓库的 **Code → Download ZIP** 下载并解压。

建议使用电脑横屏或 16:9 投影，并启用浏览器的图形加速。不同设备的 WebGL 支持、性能和屏幕比例会影响帧率与构图；手机竖屏沿用原版构图限制。
